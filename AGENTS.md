# Agent instructions

## What this is

A repo of agent skills I use every day for real engineering work.

## Structure

Skills live in [`./skills`](./skills). Each skill directory holds:

- The skill itself, structured according to the [`skill-creator`](./skills/skill-creator/) skill.
- A short README covering what the skill is, and how and when to use it.

## Keeping docs current

[`./README.md`](./README.md) must be updated at all times.
